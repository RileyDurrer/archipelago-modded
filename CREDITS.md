# Credits

This pack redistributes nothing: packwiz downloads each mod from its own
author's Modrinth or CurseForge page.

Every mod in the pack is listed in [docs/MODLIST.md](docs/MODLIST.md) with its
source, the version checked, its licence and what it does in the pack. That
list is the credit record until the pack is built. Once the mods are
installed, this file will list each mod's authors and links.

## Research
- Mod versions, sides and licences: Modrinth API (`api.modrinth.com/v2`), checked 2026-11-19 to 2026-11-21.
- Compatibility notes: the bug trackers for Create Aeronautics
  (https://github.com/Creators-of-Aeronautics/Simulated-Project) and Sable
  (https://github.com/ryanhcode/sable); specific issues are linked in the mod list.
- Player install flow ([docs/PLAYER-SITE.md](docs/PLAYER-SITE.md)), checked
  2026-11-21: packwiz docs (https://packwiz.infra.link), packwiz-installer
  source and issue #93 (https://github.com/packwiz/packwiz-installer), and the
  Prism Launcher wiki and 9.0 release notes (https://prismlauncher.org).
